TITLE
Middle-ground pseudocode: baseline_mentalize_exp3_v2.jl

PURPOSE
Compute observation schedule for each (map, scenario) in exp3 by finding the
informativeness horizon independently for agent2 and agent3, then observing
both for their full individual horizons (interleaved).

ALGORITHM
1. Load exp3 metadata, domain assets, and precomputed inference data (goal/state/world probs).
2. For each map:
3.   Load domain and ASCII problem. Initialize state.
4.   Check if agent1 needs blue wizards at all. If not → t=0 for both scenarios, skip.
5.   Load and compile agent-filtered problems (agent2-only and agent3-only ASCII maps).
6.   Enumerate belief states and find s_id for agent2 and agent3 (done once per map).
7.   For each scenario (1 and 2):
8.     Get agent2_gem and agent3_gem from metadata (the goals each agent is pursuing).
9.     Load scenario-specific goal_probs and state_probs for each agent.
10.    Run find_informativeness_horizon for agent2:
11.      Scan timesteps t=1..end; at each t check if any plausible (goal g, state s) future
12.      trajectory still matches the current state distribution. If none match → T_agent2 = t.
13.    Run find_informativeness_horizon for agent3 (same logic).
14.    Set agent2_count = T_agent2, agent3_count = T_agent3, T = T_agent2 + T_agent3.
15.    Build interleaved observations list (alternating agent2/agent3 until each count is met).
16.    Store result for this (map, scenario) key.
17. Save all results to JSON.

KEY DIFFERENCES FROM EXP1/EXP2
- Two observed agents; each gets their own independent informativeness horizon.
- Total T = T_agent2 + T_agent3 (both fully observed, not just the winner).
- Map-level setup (filtering, compiling, belief enumeration) is hoisted outside the
  scenario loop for efficiency.
- Early exit if agent1 doesn't need blue wizards (no observation needed at all).
- Problems are ASCII-format (.txt), not PDDL files.

KEY DIFFERENCES FROM baseline_mentalize_exp3.jl (v1)
- v1 took T = min(T_agent2, T_agent3) and observed only the agent that diverges first.
- v2 takes T = T_agent2 + T_agent3 and observes both agents for their full horizons.
- v2 hoists map-level setup outside the scenario loop (v1 repeated it per scenario).
- v2 extracts the divergence logic into a reusable find_informativeness_horizon function.

OUTPUT
- steps dictionary: { "map_id_scenarioN" → { observations, agent2_count, agent3_count, t } }
- step_dict_mentalize_exp3.json
