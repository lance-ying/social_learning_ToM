TITLE
Middle-ground pseudocode: baseline_non_mentalizing_exp4.jl

PURPOSE
Compute observation schedule for each (map, scenario) in exp4 using a cost-comparison
heuristic. Does not reason about which agent to observe or what their goals are —
splits observations evenly if observing is worth it at all.

ALGORITHM
1. Load exp4 metadata and domain assets (including domain_render for cost estimation).
2. For each map (sorted numerically) and each scenario (keyed as map_id_scenarioN):
3.   Load domain and ASCII problem. Initialize and compile state.
4.   Find all blue wizards in the state.
5.   Compute Q_not_observe: estimated cost of self-exploration without observing.
6.   Run A* planner. Compute Q_observe: plan cost + observe cost × T steps.
7.   T = index of first :interact with a blue wizard (or plan length if none).
8.   If Q_observe < Q_not_observe:
9.     Split T evenly: agent2_count = T ÷ 2, agent3_count = T - agent2_count.
10.    Build interleaved observations (alternating agent2/agent3).
11.    Store result with T > 0.
12.  Else: store T = 0, empty observations (skip observation entirely).
13. Save all results to JSON.

KEY DIFFERENCES FROM EXP3
- Problem directory is problems_exp4_013026 (date-stamped).
- Maps sorted numerically before processing.
- Inference file is referenced in config but not actually used (non-mentalizing is plan-based only).

OUTPUT
- steps dictionary: { "map_id_scenarioN" → { observations, agent2_count, agent3_count, t } }
- step_dict_nonmentalize_exp4.json
